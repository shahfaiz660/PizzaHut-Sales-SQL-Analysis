# 🍕 PizzaHut Sales Analysis — SQL

## 📌 Project Overview

An SQL-based analysis of PizzaHut sales data to uncover revenue
trends, product performance, order patterns, and actionable
business insights.

## 🎯 Project Objectives

- Analyze overall sales performance
- Identify top-performing pizza types
- Analyze pizza categories and sizes
- Understand order patterns by hour
- Analyze revenue contribution
- Identify high-performing products

## 🛠️ Tools Used

- MySQL
- SQL
- Canva

## 📊 Key Results

- Total Orders: **21,350**
- Total Revenue: **817,860.05**
- Most Ordered Pizza Size: **Large (L)**
- Highest-Priced Pizza: **The Greek Pizza**
- Average Pizzas Ordered Per Day: **138**

## 🔍 Analysis Performed

- Total number of orders
- Total revenue
- Highest-priced pizza
- Most common pizza size
- Top 5 most ordered pizza types
- Category-wise pizza quantity analysis
- Order distribution by hour
- Average pizzas ordered per day
- Top pizzas based on revenue
- Revenue contribution by category
- Cumulative revenue analysis
